## The one decision a reviewer should look at

**LeanGallery could NOT be added as the prescribed `[[require]]`.**  The gallery is still on plain
`import`; Lean 4.31 errors `cannot import non-module X from module`.  This repo's root
`GoodsteinPA.lean` is a `module`, so (a) an arc file that imports the gallery cannot itself be a
module, and (b) a legacy arc file cannot be imported from the module root.  There is no
configuration that bridges this, so the five hydra files were **vendored** verbatim into
`GoodsteinPA/ToMathlib/Hydra/{Basic,Engine,Ordinal,Statement,Canonical}.lean` — only the module
header changed, namespace deliberately left as `LeanGallery.Logic.Hydra` to record provenance and
keep the arc's `open` lines untouched.  The `[[require]]` and manifest entry were therefore NOT
added; the port is self-contained and needs no network.  `native_decide` in the vendored
`Canonical.lean` needed `public meta import` lines for the sibling hydra modules and
`Mathlib.Data.Nat.Pairing` (symptoms: "IR of declaration … not available" and "could not find
native implementation of external declaration `Nat.pair`").
