## ⚠️ Gotchas

* **`box done` vs `box done --green` on a scoped run.** Plain `box done` is gated on a *repo-wide*
  `sorry` check and was **declined** here even though `box` itself reported the scoped target clean.
  On a `--done-when 'sorry-free:<path>'` run the correct exit is `box done --green`.
* **`∀⁰`/`∃⁰` are g-i's own prefixes** (`GoodsteinPA/ToFoundation/Compat.lean`). A file that does
  not import `GoodsteinPA` must write upstream's `∀¹`/`∃¹`. They are the *same constants*, so the
  frozen statement's `∀⁰ ∃⁰ φ` and a lemma's `∀¹ ∃¹ φ` are literally the same term — no bridging
  lemma needed.
* **`Bounding.HierarchySymbol.Semiformula.val_rew` must be fully qualified**: bare
  `Semiformula.val_rew` is ambiguous once `FFL.FirstOrder.Bounding.HierarchySymbol` is open.
* **`rcases h : e with ...` rewrites the goal**, not just hypotheses — so inside a branch the
  follow-up is `rfl`, not `exact h`. Cost two of the three errors in the first compile of `Readoff`.
* `rw [ONote.fastGrowing_limit o hf]` leaves an unreduced beta-redex; use `simp only [...]` when the
  next rewrite must see through it.
* `modelCode (V := ℕ) o` is `((code o : ℕ) : ℕ)`; `simpa [modelCode]` (i.e. `Nat.cast_id`) bridges
  it to `code o`.
* Wu's W7 simp discipline still applies: never let a bare `simp` loose on a whole coded statement
  (`precDef`, `fgGraphDef`) — it OOM-kills the elaborator. Go through small evaluation lemmas.
